# 🍽 Freedom DMP Lunch Bot

Telegram-бот для автоматического парсинга меню столовой с картинки с помощью ИИ (Gemini) и сбора заказов в группе.

## 🚀 Как запустить локально

1. Склонируйте репозиторий: `git clone <ссылка-на-ваш-репо>`
2. Убедитесь, что у вас установлена Java 17+ (или ваша версия).
3. В настройках запуска (Environment Variables) пропишите ключи:
   * `TELEGRAM_BOT_TOKEN` = ваш токен от BotFather
   * `GEMINI_API_KEY` = ваш ключ от Google AI Studio
4. Запустите класс `LunchBotApplication`.

## 🛠 Использование в Telegram
* Добавьте бота в группу.
* Перейдите в нужный топик (ветку) и напишите `/bind`, чтобы бот привязался к нему.
* Отправьте картинку с меню прямо в этот топик.
* Напишите `/collect`, чтобы закрыть опросы и получить чек для кухни и для оплаты.
