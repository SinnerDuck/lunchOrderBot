🍽 Freedom DMP Lunch Bot
Telegram-бот для автоматического сбора заказов на обед в офисе.

Бот избавляет дежурного от рутины: он использует нейросеть (Google Gemini) для распознавания сфотографированного меню, автоматически создает удобные опросы в группе, собирает ответы коллег и формирует итоговый чек для кухни и для оплаты.

✨ Основной функционал
🤖 AI-распознавание: Читает меню по фотографии и разбивает его на категории (Первое, Второе, Салаты и т.д.) с ценами.

📊 Автоматические опросы: Публикует голосования в специальном топике группы.

🏷️ Умный расчет комбо: Автоматически группирует блюда в комплексы (первое + второе + салат + напиток) и применяет скидку.

🧾 Итоговые чеки: Генерирует сгруппированный список блюд для передачи на кухню и детальный расчет, кто сколько должен перевести.

💾 Локальная БД: Автоматически запоминает пользователей, которые взаимодействовали с ботом.

🛠 Доступные команды
/start — Приветственное сообщение бота.

/collect — Главная команда. Останавливает все активные опросы, подбивает итоги и выводит чеки (кухня + оплата).

/tagall (или /all) — Отмечает всех известных боту пользователей в топике, чтобы никто не забыл заказать обед.

🚀 Как запустить бота (Инструкция для дежурного)
Проект написан на Java (Spring Boot). Для запуска локально на компьютере вам понадобится установленная среда разработки (например, IntelliJ IDEA).

1. Скачивание проекта
Склонируйте репозиторий на свой компьютер:

2. Настройка ключей доступа (Environment Variables)
В целях безопасности токены от Telegram и ключ от ИИ не хранятся в коде. Перед запуском их нужно указать в настройках:

В правом верхнем углу IDEA нажмите на Edit Configurations... (возле кнопки Play).

Найдите поле Environment variables.

Вставьте туда ключи (запросите актуальные ключи у ответственного лица) в формате:Plaintext

TELEGRAM_BOT_TOKEN=ваш_токен_от_бота;GEMINI_API_KEY=ваш_ключ_от_gemini
3. Запуск и использование
Запустите приложение (кнопка Run ▶️).

В рабочем топике Telegram отправьте боту фотографию меню на сегодня.

Дождитесь, пока бот создаст опросы (это занимает пару секунд).

Когда все коллеги проголосуют, отправьте в топик команду /collect.

Бот выдаст итоговые чеки. После этого приложение в IDEA можно останавливать до следующего дня.
